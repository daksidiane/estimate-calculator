# Калькулятор сметы по прайсу заказчика

Проблема бизнеса: Менеджеры считали сметы в таблицах и вручную переносили цены. В расчётах регулярно появлялись ошибки.

Калькулятор считает стоимость по актуальной базе на основе выбранных опций и собирает PDF с коммерческим предложением.

Команда собирает сметы без ручного ввода цен и сразу получает оформленный документ. Бизнес сохраняет историю расчётов и скидок по каждому клиенту.

## Как попробовать

Нужны Windows и программа [Node.js](https://nodejs.org/) (кнопка LTS). При установке ничего не меняйте, просто жмите «Next».

1. На этой странице нажмите зелёную кнопку **Code** → **Download ZIP**.
2. Распакуйте архив в любую папку, например на Рабочий стол.
3. Откройте внутри папку `calc`.
4. Кликните по адресной строке Проводника (там, где путь к папке), напишите `cmd` и нажмите Enter. Откроется чёрное окно.
5. Введите `npm install` и нажмите Enter. Первый раз это займёт несколько минут. Дождитесь приглашения вводить снова.
6. Введите `npm start` и нажмите Enter.

Откроется окно «Калькулятор конструкций». Цены уже лежат в образце.

Окно с командами не закрывайте, пока пользуетесь калькулятором. Чтобы выйти: закройте окно калькулятора и в чёрном окне нажмите Ctrl+C.

## Как пользоваться

1. Выберите изделие, размеры и опции.
2. Проверьте сумму.
3. Сохраните коммерческое предложение в PDF.

Обновление прайса не меняет уже выданные предложения.
