# Калькулятор сметы по прайсу заказчика

Менеджеры считали сметы в таблицах и вручную переносили цены. В расчётах регулярно появлялись ошибки.

Калькулятор считает стоимость по актуальной базе на основе выбранных опций и собирает PDF с коммерческим предложением.

Команда собирает сметы без ручного ввода цен и сразу получает оформленный документ. Бизнес сохраняет историю расчётов и скидок по каждому клиенту.

## Установка и запуск

Нужны Windows и [Node.js](https://nodejs.org/) 18 или новее.

```cmd
cd calc
npm install
npm start
```

Откроется окно «Калькулятор конструкций». Цены берутся из локальной базы в проекте.

Чтобы пересобрать базу из таблицы Excel:

```cmd
python create_database.py
```

Сборку установщика для Windows:

```cmd
cd calc
npm run dist
```

## Как пользоваться

1. Выберите изделие, размеры и опции.
2. Проверьте сумму. При необходимости обновите базу кнопкой в шапке.
3. Сохраните коммерческое предложение в PDF.

Обновление прайса не меняет уже выданные предложения.
